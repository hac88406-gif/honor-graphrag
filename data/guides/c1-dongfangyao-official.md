# 曜 · 官方数据聚合

- 英雄：曜（星辰之子）
- 分路：打野 / 对抗路
- 上手难度：40

## 技能描述（官方原文）
- **星辰之赐**：曜技能命中敌方单位时将回复70~140(+2%额外生命)点生命，未命中目标回复效果减半。每次释放技能时，获得一层星辰之力，当星辰之力充盈时，曜获得一次强化技能使用权，持续三秒，强化技能释放后会强化下次普攻，使用强化普攻会向敌人发起冲锋，额外造成80~160(+27%物理攻击)物理伤害。
- **裂空斩**：快速旋转剑刃，对周围的敌人造成340/408/476/544/612/680(+115%额外物理攻击)物理伤害。
- **逐星**：向左侧快速移动，对路径上的敌人造成180/216/252/288/324/360(+70%额外物理攻击)物理伤害与25/30/35/40/45/50%减速(1.5秒)。
——半招剑法，得自游历四方的少年剑客，取神来一笔，飞燕逐星之意。
- **归尘**：回到2秒前的位置(无法移动超过650距离)，清除星削，并对路径与终点的敌人造成420/630/840(+140%额外物理攻击)法术伤害。
被动：曜所受伤害的25%/37.5%/50%将会转化为星削在2秒内结算。

## 最佳搭档（官方原文理由）
- 鬼谷子：曜虽然自身也能够快速接近对手，但就容易失去其爆发力，在鬼谷子的帮助下，情况就会有所不同
- 李白：通过李白的大招，可以将敌方血量压低，作为偏向技巧和收割的曜来说，李白可以帮其创造出一定的收割空间

## 压制英雄（官方原文理由）
- 阿轲：阿轲的爆发力十足，但只要曜有所准备就能够将大部分伤害避免掉
- 孙悟空：固定的伤害节奏，给予了曜非常大的操作空间，频繁的位移能力也可躲开控制范围

## 被压制英雄（官方原文理由）
- 孙尚香：灵活的身手让其很难被曜接近，且能非常轻松的将曜消耗
- 王昭君：大范围的持续伤害，让曜无法通过大招避免太多伤害，自身的硬度也能够避免被秒杀

## 官方铭文与出装说明
- 铭文搭配一：宿命、怜悯、狩猎
- 铭文搭配二：圣人、虚空、轮回
- 推荐出装一：影忍之足 → 暗影战斧 → 暴烈之甲 → 魔女斗篷 → 碎星锤 → 名刀·司命
- 推荐出装二：巡守利斧 → 抵抗之靴 → 暗影战斧 → 冰痕之握 → 碎星锤 → 魔女斗篷
- Tips：常规出门装，半肉出装，能缠斗，有爆发，能够更好的等待缠斗2秒后的大招伤害爆发，高冷却带来更多的技能释放，在中后期能够为团队吸收伤害并且充当侧翼绞杀的角色
- Tips：常规出门装，高冷却一击即走，能够通过宗师之力获得更大的爆发伤害，需要仔细计算累积的星辰之力，通过爆发力制造伤害为团队做出贡献
