# 李元芳 · 官方数据聚合

- 英雄：李元芳（王都密探）
- 分路：发育路 / 打野
- 上手难度：50

## 技能描述（官方原文）
- **密探谛听**：元芳可以通过谛听获得并捕捉敌方英雄的踪迹，获得敌方视野1秒，对同一单位每8～4秒生效一次。
同时李元芳可以识破野怪的弱点，所有的攻击会对野怪和小兵额外造成5~10%物理伤害。
- **谍影重重**：元芳使用暗印标记敌方目标，4秒后爆炸对范围内敌方造成220/264/308/352/396/440(+70%物理攻击)物理伤害，元芳的普攻会叠加暗印标记，最多叠加4层，每层印记会额外造成90/108/126/144/162/180(+65%物理攻击)物理伤害，叠满4层会立即引爆暗印。
释放技能时元芳会增加35/42/49/56/63/70%攻击速度和50/60/70/80/90/100点攻击距离，持续4秒。
- **刃遁**：元芳放出飞轮后施展鬼魅身法在终点接住飞轮，移动时无法被选中，飞轮会对敌人造成260/312/364/416/486/520(+80%物理攻击)物理伤害并减少15%/18%/21%/24%/27%/30%移速，持续2秒。经过的地面留下燃痕，持续2.9秒，对路径上的敌人每0.25秒造成110/132/154/176/198/220(+30%物理攻击)物理伤害并减少15%/18%/21%/24%/27%/30%移速。
- **无间刃风**：元芳扔出飞轮卷起利刃风暴对目标造成320/480/640(+100%物理攻击)物理伤害，持续5.4秒，对范围内的敌人每0.5秒造成140/210/280(+40%物理攻击)物理伤害并减少25/37.5/50%移速。
内圈会受到双倍的刃伤，刃伤也可叠加暗印层数。

## 最佳搭档（官方原文理由）
- 白起：白起：作为目前版本唯一有嘲讽技能的英雄，白起的控制和坦克效果极强，李元芳的一技能飞镖拥有AOE爆炸效果，如果敌方英雄聚在一起，很容易打出较高的爆炸伤害，元芳的大招也有比较强的AOE伤害，白起如果2技能配合大招同时嘲讽控制敌方多名英雄，李元芳1技能接大招可以轻松打出爆炸伤害。
- 墨子：墨子：李元芳到了后期，他的输出和射程相对其他射手会差一些，拥有高额伤害和远程poke控制能力的墨子可以为李元芳补足短板，墨子的大招同时控制多人也可以配合李元芳完成爆炸输出。

## 压制英雄（官方原文理由）
- 兰陵王：兰陵王：兰陵王的核心玩法是隐身后先手秒杀敌方核心输出点，有李元芳的被动在可以轻松探测到敌方兰陵王的位置和动态，强大的反隐效果可以让兰陵王失去gank己方核心输出位的机会，躲避好兰陵王的2技能后站撸也可以轻松击杀兰陵王。
- 阿轲：阿轲：阿轲前期比较依赖野区资源需要发育，4级前很难有gank抓人能力，而李元芳可以快速清线支援，李元芳被动的监听效果也可以限制阿轲的大招隐身效果，在被阿轲gank时不光可以观察到敌方动向，还可以利用大招减速和2技能位移与阿轲拉开距离，1技能后的攻速提升可以让李元芳在短时间内打出高额伤害。

## 被压制英雄（官方原文理由）
- 兰陵王：兰陵王的隐身和秒杀能力很容易接近李元芳将其秒杀
- 花木兰：花木兰的超高爆发输出能力能快速击杀走位不慎的元芳

## 官方铭文与出装说明
- 铭文搭配一：红月、鹰眼、隐匿
- 铭文搭配二：圣人、虚空、轮回
- 推荐出装一：追击刀锋 → 急速战靴 → 泣血之刃 → 暗影战斧 → 无尽战刃 → 闪电匕首
- 推荐出装二：追击刀锋 → 急速战靴 → 泣血之刃 → 无尽战刃 → 仁者破晓 → 贤者的庇护

- Tips：当敌方多位英雄物理防御较高时，破晓能够提供的破甲效果是李元芳必备的属性
