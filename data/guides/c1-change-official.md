# 嫦娥 · 官方数据聚合

- 英雄：嫦娥（寒月公主）
- 分路：中路 / 对抗路 / 打野
- 上手难度：40

## 技能描述（官方原文）
- **月盈**：嫦娥在7.5~6秒内获得一次盈月之力：获得强化普攻（可存储2次），造成110~220(+0.2法术攻击)法术伤害和25%~50%减速效果，并回复60~120(+1%额外生命值)法力值。技能每对英雄造成一次伤害，减少1%盈月之力的冷却
满蓝时，嫦娥技能回复的法力值会转换为等额的生命回复
嫦娥使用归月回城后，可使用奔月飞回原来的位置
- **月辰**：嫦娥朝指定方向推出能量球，能量球到达最大距离后会返回自身。能量球对首个命中的英雄造成8次30/36/42/48/54/60(+6%法术攻击)法术伤害和1.5秒定身，并获得20/24/28/32/36/40%移速，持续2秒。
能量球对小兵造成全额伤害，且每次穿过非英雄单位减少0.5~0.25秒定身时长，最多4次。
- **月璇**：嫦娥在身边和指定位置召唤法力旋涡持续5秒，每次对范围内敌人造成16次70/84/98/112/126/140(+14%法术攻击)法术伤害，消耗15点法力(不足消耗部分转为等额法术伤害)，并为自身回复10/12/14/16/18/20(+0.15%额外生命值)法力，并且指定位置处的法力旋涡会吸附附近的兵线。
法力旋涡为嫦娥提供6%/7.2%/8.4%/9.6%/10.8%/12%伤害减免。
再次使用可以提前关闭法力漩涡。多个法力旋涡对同一单位造成一次效果。
- **月芒**：嫦娥随机向周围持续倾泻法力弹幕，对命中的敌人造成70(+9%法术攻击)法术伤害，倾泻法力期间自身增加30%移速。
法力值足够时会产生额外子弹，每颗子弹消耗50点法力，造成等额伤害并回复80(+1.2%额外生命值)生命。
3秒内持续按压释放，取消按压后会在0.5秒内继续发射子弹，期间可以使用技能和强化普攻。

## 最佳搭档（官方原文理由）
- 鬼谷子：嫦娥大招爆发范围不小，但作为法师来说还是太近了，需要鬼谷子的帮助，让其靠近敌人
- 白起：嫦娥虽然坦度不错，但是并不能作为主动吸收伤害的角色，在团队里最好在配置一位坦克英雄进行开团和吸收伤害

## 压制英雄（官方原文理由）
- 上官婉儿：上官婉儿的大招移动路径比较容易预判，嫦娥的1技能即使再缓慢还是能够逼退
- 李白：李白可以给予后排法师极大的压力，嫦娥虽然也是法师，但具有坦克的属性，不会被李白的刺杀轻易的压制

## 被压制英雄（官方原文理由）
- 伽罗：伽罗拥有超远的射程和强势减速能力，这让嫦娥入场十分困难，并且在进入战斗前就会把嫦娥的蓝量削减至可以承受的范围内
- 吕布：吕布真实伤害可以越过嫦娥的护盾直接削减嫦娥的血量，非常克制依赖护盾减伤的嫦娥

## 官方铭文与出装说明
- 铭文搭配一：圣人、心眼、调和
- 铭文搭配二：圣人、虚空、轮回
- 推荐出装一：秘法之靴 → 时之预言 → 炽热支配 → 博学者之怒 → 极寒风暴 → 痛苦面具
- 推荐出装二：秘法之靴 → 圣杯 → 炽热支配 → 痛苦面具 → 博学者之怒 → 虚无法杖
- Tips：时之预言可以为嫦娥前中期带来足够的续航，炽热支配者的被动会让处于团队中前排的嫦娥面对控制时，得到关键的喘息时间避免被秒杀
- Tips：嫦娥大量倾泻法力值是可以轻松造成高额的范围伤害，如果队友能够支撑其前排给予输出环境，嫦娥可以选择全法攻出装
